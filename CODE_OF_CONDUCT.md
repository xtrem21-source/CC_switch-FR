# Code de conduite

## Notre engagement

Ce projet veut rester un espace de travail technique, direct et respectueux. Participer implique
de :

- critiquer les traductions et le code, pas les personnes ;
- supposer la bonne foi, demander une précision avant de conclure à une erreur ;
- accepter qu'un désaccord de traduction se tranche par l'usage réel dans l'interface, pas par
  l'insistance ;
- ne pas publier de donnée personnelle (chemin, jeton, capture contenant une clé) dans une issue
  ou une pull request.

## Comportements inacceptables

- Insultes, harcèlement, propos discriminatoires.
- Publication de secrets ou de données personnelles d'autrui.
- Pollution volontaire des échanges.

## Portée

Issues, pull requests, discussions et toute communication publique liée au projet.

## Signalement

Problème de **conduite** : ouvrez une issue en décrivant les faits, sans données personnelles.
Problème de **sécurité** : canal privé décrit dans [SECURITY.md](SECURITY.md).

Le mainteneur peut éditer, masquer ou fermer toute contribution qui viole ce code.
